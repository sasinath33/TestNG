📖 Chapter 11: Reports in TestNG

11.1 Why Reports?

Reports are essential because they:

Provide a summary of test execution (passed, failed, skipped).

Help identify issues quickly.

Allow stakeholders to track progress and quality.

11.2 Default TestNG Reports

When you run a suite, TestNG automatically generates reports in the test-output folder:

index.html → Summary of all tests.

emailable-report.html → A simple report that can be shared via email.

testng-results.xml → XML format for integration with CI/CD tools.

Example Output (index.html)

Total tests run: 10

Passed: 8

Failed: 2

Skipped: 0

11.3 Customizing Reports with Listeners

You can use ITestListener to log custom messages into reports.

For example, capturing screenshots on failure and attaching them to reports.

java

@Override

public void onTestFailure(ITestResult result) {

System.out.println("Test Failed: " result.getName());

// Code to capture screenshot can be added here


}

11.4 Extent Reports

Extent Reports is a popular library for creating beautiful, interactive HTML reports.

Maven Dependency

xml

<dependency>

<groupId>com.aventstack</groupId>

<artifactId>extentreports</artifactId>

<version>5.0.9</version>

</dependency>

Example: Extent Report Integration

java

import com.aventstack.extentreports.ExtentReports;

import com.aventstack.extentreports.ExtentTest;

import com.aventstack.extentreports.reporter.ExtentHtmlReporter;

import org.testng.annotations.*;

public class ExtentReportDemo {

ExtentReports extent;

ExtentTest test;

@BeforeSuite

public void setupReport() {

ExtentHtmlReporter reporter = new ExtentHtmlReporter("extentReport.html");

extent = new ExtentReports();

extent.attachReporter(reporter);

}

@Test

public void sampleTest() {

test = extent.createTest("Sample Test");

test.pass("Test Passed Successfully!");

}

@AfterSuite

public void tearDownReport() {

extent.flush();

}

}

Output

A colorful HTML report with:

Test status (pass/fail/skip)

Logs and screenshots

Interactive charts

11.5 Notes

Default TestNG reports are simple but sufficient for small projects.

Extent Reports are recommended for professional frameworks.

Reports can be integrated with Jenkins for CI/CD pipelines.
